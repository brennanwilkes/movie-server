## 1. THE BLIND TEST KILLED blockMean. DO NOT REVIVE IT.

Eleven films Brennan had actually watched, judged on his phone (so the theme-overlay bug below was
not a confound), scored 1 = artifacts / 0.5 = maybe / 0 = clean:

| | Spearman vs the eye |
|---|---:|
| src Mb/s | 0.905 |
| complexity | 0.824 |
| R (bitrate adequacy) | 0.146 |
| blurMean | −0.266 |
| **blockMean** | **−0.090** |

Films `blockMean` called clean averaged a WORSE verdict (0.70) than the ones it called blocky (0.58).
Three false positives (Spirited Away 99th pct, I Am Legend 97th, Inception 99th — all judged fine)
and three false negatives (Star Wars 3rd pct, Jurassic Park 2nd, Taxi Driver 2nd — all judged bad).

`wBPP+ = BPP+ × (1.33/blockMean)^0.40` would have **promoted the three worst-looking files** and
demoted two of the three clean ones. It was never shipped. The exponent is not too large — the
correlation is zero, so there is no exponent that helps.

## 2. WHAT THE NOISE ACTUALLY IS: grain boiling

Two independent discriminators, on the file itself (`scripts/probe-noise-origin.sh` +
`analyze-noise-origin.js`), bright pixels only, scene cuts excluded:

| | Star Wars 9:19 (artifacts) | No Other Choice (clean, grain-free) |
|---|---:|---:|
| pbFloor — noise/frame | 2.64 | 1.78 |
| **iRatio** — I-frame diff ÷ P/B diff | **1.01** | 0.44 |
| **gridRatio** — across-block ÷ inside-block | **1.165** | **0.995** |

**Temporally it is grain** — renewed every frame, no jump at keyframes. Compression noise freezes
inside a GOP and cannot do that. **Spatially it carries the codec's 8×8 fingerprint** against a
0.995 clean baseline. So: the film's own grain, quantised imperfectly. Grain boiling.

Consequences:
- **`R` is contaminated as a reference** (a CRF-20 encode of a grainy film boils too), which is why
  R scored 0.146 against the verdicts. This is a structural problem with BPP+'s denominator.
- **`gridRatio` is the promising penalty term** — it isolates the part more bits can fix. That is the
  exact opposite of blockMean, which measured the part they cannot.
- More bits reduce the boiling but the grain stays, so no upgrade makes Star Wars look like No Other
  Choice, and it must not be scored as if it could.

Why Brennan only ever sees it in **bright** areas: grain lives in the highlights and nothing masks it
there. Why he never saw it before: **the projector is native 720p**, so every 1080p file is
downscaled ~44% before display — an effective grain filter. He saw it first on a phone, at native
resolution. It is not visible on the projector at all.

**n=2.** A direction, not a coefficient. Easy Rider failed as a third control: 245 of 249 frames were
dropped as camera motion. The measurement needs STATIC BRIGHT scenes, which is the real obstacle to
running it library-wide.

## 4. TRAPS

1. **Host ffmpeg is 4.2 and has NO `blockdetect`/`blurdetect`** — fails silently, empty columns.
   Always run detector work via `docker exec controller` (ffmpeg 5.1).
2. **`-vf` is an OUTPUT option** and must precede the output URL, or ffmpeg emits nothing.
3. **I-frames are inserted AT scene cuts**, so a naive iRatio reports "compression" on any clip
   containing one. The cut guard in `analyze-noise-origin.js` is mandatory — without it Spirited Away
   (hand-drawn, no grain, judged clean) scored 2.23 "COMPRESSION".
4. **The frame-type ffprobe interval must cover every decoded frame**, or later frames read as `?`
   and a keyframe inside the window is silently averaged into the P/B floor.
5. **`killProbe()` sends SIGKILL, which cannot be trapped** — a script-side cleanup handler is not a
   possible fix for the zombie leak. Reaping at PID 1 is the only place it can be solved.
6. **This box has 4 cores.** Run encode experiments strictly sequentially.
7. **A single `top`/`docker stats`/`iostat` sample lies.** Sample properly before claiming a process
   is eating the box.
8. **Judge only films Brennan has WATCHED.** A first-time viewer cannot separate "this encode looks
   wrong" from "this film always looked like that". The first blind list was mostly unseen films and
   had to be rebuilt from Jellyfin's played list.
